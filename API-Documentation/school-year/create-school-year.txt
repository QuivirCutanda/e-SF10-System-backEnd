--------------------------------------------------
## Create School Year
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Content-Type
        Value:application/json
    -Method
        POST
    -EndPoint
         http://localhost:3001/esf10/school-year/create-school-year

    -Body:raw

--------------------------------------------------
Example requist
--------------------------------------------------

{
  "start_year": 2027,
  "end_year": 2028
}



--------------------------------------------------

-------------------------------------------------
{
    "success": true,
    "message": "School year created successfully",
    "schoolYear": {

        "start_year": 2027,

    },
