--------------------------------------------------
## Create admin account (Full access)
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Content-Type
        Value:application/json
    -Method
        POST
    -EndPoint
       http://localhost:3001/esf10/register-Admin

    -Body:raw
--------------------------------------------------
Example requist
--------------------------------------------------

{
  "first_name": "admin",
  "middle_name": "admin",
  "last_name": "admin",
  "email": "quivircutandaanora.com",
  "password": "nopassword",
  "role": "admin"
}


--------------------------------------------------
Example response
-------------------------------------------------
{
    "message": "Admin registered successfully",
    "token": "your generated token"
}
