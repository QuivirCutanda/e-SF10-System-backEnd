--------------------------------------------------
## register User account
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Content-Type
        Value:application/json
    -Method
        POST
    -EndPoint
       http://localhost:3001/esf10/register-user
    -Body:raw
--------------------------------------------------
Example requist
--------------------------------------------------

{
  "first_name": "Teacher",
  "last_name": "test",
  "email": "teacher@gmail.com",
  "password": "securepassword123",
  "role": "teacher"
}
