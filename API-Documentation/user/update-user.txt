--------------------------------------------------
## update user account
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Authorization
        Value:Bearer paste your generated token here
    -Method
        PUT
    -EndPoint
       http://localhost:3001/esf10/update-user/<user_id>

    -Body:raw
--------------------------------------------------
Example requist
--------------------------------------------------

{
  "first_name": "Quivir",
  "middle_name": "A",
  "last_name": "Cutanda",
  "email": "new.email@example.com",
  "password": "nopassword",
  "role": "teacher"
}


--------------------------------------------------
