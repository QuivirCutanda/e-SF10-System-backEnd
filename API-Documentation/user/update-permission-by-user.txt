--------------------------------------------------
## update Permission by User
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Authorization
        Value:Bearer paste your generated token here
    -Method
        PUT
    -EndPoint
       http://localhost:3001/esf10/user/<user_id>/permissions

    -Body:raw

    *only one permission per requist
--------------------------------------------------
Example requist
--------------------------------------------------

{
    "permission_name": "manage_permissions",
    "is_granted": true
}
