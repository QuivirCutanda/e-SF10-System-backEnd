--------------------------------------------------
## update user password
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Authorization
        Value:Bearer paste your generated token here
    -Method
        PUT
    -EndPoint
       http://localhost:3001/esf10/user/<user_id>/update-password

    -Body:raw
--------------------------------------------------
Example requist
--------------------------------------------------

{
  "currentPassword": "securepassword123",
  "newPassword": "no"
}


--------------------------------------------------
Example response (200 OK)
-------------------------------------------------
{
    "message": "Password updated successfully"
}
