## View all activity log
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Authorization
        Value:Bearer paste your generated token here
    -Method
        GET
    -EndPoint
       http://localhost:3001/api/activity-logs?page=1&limit=10
