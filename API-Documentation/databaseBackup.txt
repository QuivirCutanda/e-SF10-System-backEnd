## Database Backup Management
--------------------------------------------------

#Prerequisites
  - Authorization
    - Headers:
      Key: Authorization
      Value: Bearer your_token_here
  - All endpoints require 'manage_backups' permission

--------------------------------------------------
## 1. Create Database Backup
--------------------------------------------------
- Method: POST
- Endpoint: http://localhost:3001/esf10/backups/create

Response (200 OK):
Download automatically.

--------------------------------------------------
## 2. List All Backups
--------------------------------------------------
- Method: GET
- Endpoint: http://localhost:3001/esf10/backups

Response (200 OK):
[
  {
    "backup_id": 1,
    "backup_filename": "backup-2025-05-25T12-45-30-000Z.sql",
    "backup_date": "2025-05-25T12:45:30.000Z",
    "user_id": 1,
    "user_name": "vincent admin"
  },
  {
    "backup_id": 2,
    "backup_filename": "backup-2025-05-26T09-15-22-000Z.sql",
    "backup_date": "2025-05-26T09:15:22.000Z",
    "user_id": 1,
    "user_name": "admin admin"
  }
]

Response (500 Internal Server Error):
{
  "message": "Failed to retrieve backups",
  "error": "Error message details"
}


--------------------------------------------------
## 2. Open or Download the specific sql file back up
--------------------------------------------------
Authorization
    - Headers:
      Key: Authorization
      Value: Bearer your_token_here
      
- Method: GET
- Endpoint: http://localhost:3001/esf10/backups/<backup_filename>
  
  example: http://localhost:3001/esf10/backups/backup-2025-06-08T09-20-02-889Z.sql

Response (200 OK):
the response is the content of the sql file
