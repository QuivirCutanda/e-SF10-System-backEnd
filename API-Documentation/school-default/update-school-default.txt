--------------------------------------------------
## udate School Default
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Content-Type
         Value:Bearer paste your generated token here
    -Method
        POST
    -EndPoint
       http://localhost:3001/esf10/school-defaults/<school_id>

    -Body:form-data
--------------------------------------------------
Example requist
--------------------------------------------------
required form
key                 type             Value
school_id           file            1234555554
school_name         text            Example School
school_address      text            123 Main St
region              text            Region 7
division            text            Division A
district            text            District B
school_head         text            John Doe
contact_number      text            09989888990
email               text            school@example.com
website             text            www.example.com
school_logo         file            examplefile.pdf(.png,jpg)
