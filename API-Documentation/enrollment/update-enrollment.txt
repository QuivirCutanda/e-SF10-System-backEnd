--------------------------------------------------
## Update enrollment
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Content-Type
        Value:application/json
    -Method
        PUT
    -EndPoint
         http://localhost:3001/esf10/enrollments/update/:enrollment_id

    -Body:raw
--------------------------------------------------
Example requist
--------------------------------------------------

{
  "student_id": 3,
  "school_year_id": 1,
  "grade_level_id": 1,
  "section_id": 1,
  "curriculum_id": 1,
  "enrollment_date": "2025-08-27",
  "status": "Pending"
}
