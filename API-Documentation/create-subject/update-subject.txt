--------------------------------------------------
## Update Subject
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Content-Type
        Value:application/json
    -Method
        PUT
    -EndPoint
       http://localhost:3001/esf10/subjects/update-subject/:subject_id

    -Body:raw
--------------------------------------------------
Example requist
--------------------------------------------------

{
  "subject_code": "MATH201",
  "subject_name": "Advanced Mathematics",
  "description": "Covers algebra, calculus, and probability.",
  "grade_levels": [1, 2, 3]
}



--------------------------------------------------
Example response
-------------------------------------------------
{
    "success": true,
    "message": "Subject updated successfully",
    "data": {
        "subjectId": 1,
        "changes": {
            "subject": true,
            "gradeLevels": {
                "added": 0,
                "removed": 0,
                "updated": 0
            }
        }
    }
}
