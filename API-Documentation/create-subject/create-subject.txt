--------------------------------------------------
## Create subject
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Content-Type
        Value:application/json
    -Method
        POST
    -EndPoint
         http://localhost:3001/esf10/subjects/create-subject

    -Body:raw
--------------------------------------------------
Example requist
--------------------------------------------------

{
  "subject_code": "MATH101",
  "subject_name": "Basic Mathematics",
  "description": "Introduction to algebra, geometry, and number theory.",
  "grade_level_ids": [1, 2], 
  "is_required": true,
  "units": 3
}




--------------------------------------------------
