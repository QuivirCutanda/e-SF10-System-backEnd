--------------------------------------------------
## Upload Scanned Document
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Authorization
        Value:Bearer paste your generated token here
    -Method
        POST
    -EndPoint
        http://localhost:3001/esf10/students/upload-sf10/<studentId>

    -Body:form-data
--------------------------------------------------
Example requist
--------------------------------------------------
required form
key           type             Value
sf10          file            examplefile.pdf(.png,jpg,docs)
start_year    text            2024
end_year      text            2025
section       text            emerald
grade_level   text            12
