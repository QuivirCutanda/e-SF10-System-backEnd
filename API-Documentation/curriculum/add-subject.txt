--------------------------------------------------
## Add subject
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Content-Type
        Value:application/json
    -Method
        POST
    -EndPoint
         http://localhost:3001/esf10/curriculum/add-subjects/:curriculum_id

    -Body:raw

    *Note: subject ID is base on Subject ID created
--------------------------------------------------
Example requist
--------------------------------------------------
*option 1: assign Subject

{
  "subject_ids": [1, 2, 3]
}


*Option 2: assign subject and assign subject into grade level

"grade_level_ids": {
    "1": [7, 8],
    "2": [9],
    "3": [10, 11, 12]
  }
