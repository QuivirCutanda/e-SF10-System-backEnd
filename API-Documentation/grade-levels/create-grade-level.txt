--------------------------------------------------
## Create Grade Level
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Content-Type
        Value:application/json
    -Method
        POST
    -EndPoint
         http://localhost:3001/esf10/grade-levels/create

    -Body:raw
--------------------------------------------------
Example requist
--------------------------------------------------

{
  "grade_code": "G6",
  "grade_name": "Grade 6",
  "grade_order": 6
}
