--------------------------------------------------
## Update Grade level
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Content-Type
        Value:application/json
    -Method
        PUT
    -EndPoint
         http://localhost:3001/esf10/grade-levels/update/:grade_level_id

    -Body:raw
--------------------------------------------------
Example requist
--------------------------------------------------

{
  "grade_code": "G7",
  "grade_name": "Grade 1",
  "grade_order": 7
}




--------------------------------------------------

-------------------------------------------------
{
    "success": true,
    "message": "Grade level updated successfully",
    "data": {
        "grade_level_id": 1,
        "grade_code": "G7",
        "grade_name": "Grade 1",
