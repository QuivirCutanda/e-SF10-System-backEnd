--------------------------------------------------
## Update Teacher
--------------------------------------------------

#Prerequisites
    -Headers (add)
        Key:Authorization
        Value:Bearer paste your generated token here
    -Method
        PUT
    -EndPoint
         http://localhost:3001/esf10/teachers/update/:teacher_id

    -Body:raw
--------------------------------------------------
Example requist
{
  "first_name": "Juan",
  "middle_name": "Reyes",
  "last_name": "Dela Cruz",
  "extension_name": "Jr.",

  "date_of_birth": "1985-05-12",
  "email": "juan.delacruz@example.com",
  "contact_number": "09181234567",
  "is_active": true
}
