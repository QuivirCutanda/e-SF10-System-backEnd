--------------------------------------------------
## create-class-schedule
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Content-Type
        Value:application/json
    -Method
        POST
    -EndPoint
          http://localhost:3001/esf10/class-schedules/create

    -Body:raw
--------------------------------------------------
Example requist
--------------------------------------------------

{
  "subject_id": 6,
  "teacher_id": 2,
  "section_id": 1,
  "school_year_id": 1,
  "day_of_week": "Monday",
  "start_time": "10:00:00",
  "end_time": "13:30:00"
}
