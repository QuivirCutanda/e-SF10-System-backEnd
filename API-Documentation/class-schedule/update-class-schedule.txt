--------------------------------------------------
## update-class-schedule
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Content-Type
        Value:application/json
    -Method
        PUT
    -EndPoint
        http://localhost:3001/esf10/class-schedules/update/:schedule_id

    -Body:raw
--------------------------------------------------
Example requist
--------------------------------------------------

{
  "subject_id": 1,
  "teacher_id": 2,
  "section_id": 1,
  "school_year_id": 1,
  "day_of_week": "Tuesday",
  "start_time": "10:00:00",
  "end_time": "11:30:00"
}
