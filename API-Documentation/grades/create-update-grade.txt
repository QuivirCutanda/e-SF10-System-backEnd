--------------------------------------------------
## create-update-grade
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Content-Type
        Value:application/json  
    -Method
        POST
    -EndPoint
        http://localhost:3001/esf10/grades/create-or-update

    -Body:raw
--------------------------------------------------
Example requist
--------------------------------------------------
{
  "enrollment_id": 1,
  "subject_id": 1,
  "grading_period": "2nd",
  "grade": 89
}


--------------------------------------------------
Example response
-------------------------------------------------
{
    "success": true,
    "message": "Grade input disabled for ALL assignments of this teacher",
    "newStatus": false,
    "timestamp": "2025-09-09T08:46:28.218Z"
}
