--------------------------------------------------
## Create role and Assign permission base on permission ID
--------------------------------------------------

#Prerequisites
    -Autorization
        No Auth
    -Headers (add)
        Key:Content-Type
        Value:application/json
    -Method
        POST
    -EndPoint
       http://localhost:3001/esf10/roles/create-role

    -Body:raw
--------------------------------------------------
Example requist
--------------------------------------------------

{
  "role_name": "staff10",
  "permission_ids": [1, 3, 6, 19] // e.g., approve_transfers, view_student_info, view_ecards, view_logs
}
